## ⭐ Featured Project

### 🗓️ Watira (وتيرة) - Smart Timetable Planner for University Students
[**Source Code**](https://github.com/anas-roshdi/watira-app) | [**Download APK**](https://github.com/anas-roshdi/watira-app/releases/latest) | Google Play: coming soon

Students enter their courses and sections, set their preferences (days off, morning or evening, maximum gaps, study load), and the app suggests the three best conflict-free timetables with a score for each. Arabic right-to-left interface.

* **App:** React Native (Expo), TypeScript, Expo Router, NativeWind
* **API:** Node.js, Express, Prisma, PostgreSQL, JWT, Zod, with 230+ automated tests
* **Delivery:** Render, Neon, Brevo (email), EAS Build
